
# THE CODEX — the statute book in the bag

Read with `references/satchel.md` (the doctrine: five laws, dispositions, controls, routing) at Stage 1
(overlay selection) and Stage 4 (rule fetch). This file is the clause mass. The digital-marketing
overlay for the American and European industries is a separate file, `references/digital-marketing-overlay.md`,
written in the same row format and read whenever the target is an agency, a martech vendor, a lead-gen
network, or a business whose marketing was built by one. Every row: **Rule · Cite · Observable test · Ceiling · Route**.

**Cite status glyphs.** ✔ = primary text fetched and read 2026-09-15. ◐ = reported by a secondary
source or cited from memory — **fetch the live text before it appears in a CONFIRMED finding** (law 5).
Ceilings: **C** = CONFIRMED-capable from observable evidence (deterministic display/disclosure rules);
**K** = CANDIDATE-only (needs facts you cannot see — intent, substantiation, spend, licensing status not
yet checked). Routes use the main card's codes. Thresholds, medium clauses and obligation-bearers are
controls, not footnotes — run them before writing a row up.
